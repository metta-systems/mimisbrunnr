# Unix interoperability and FUSE — implementation plan

Design: [unix-design.md](unix-design.md) · Decisions: [unix-decisions.md](unix-decisions.md) · Order: [operations-plan.md](operations-plan.md)

- [ ] **UNIX1 — Paths from the index.** Path resolution, directory listing and name search go through the hierarchical `unix-path` key (UNIX-DESIGN "Selected design"); `PathContextManager`, path contexts, its boot-time rebuild, `PathProjection::reverse_lookup`'s scan and `path_contexts_bytes` in the legacy blob go. Prerequisites: [INDEX18](index-implementation-plan.md), [INDEX19](index-implementation-plan.md). Acceptance: import a tree, commit, reopen: `/paths/` lists the same paths with nothing rebuilt at mount; resolving a path reads a number of blocks that does not grow with the number of paths (counted). Unblocks [ENGINE8](engine-implementation-plan.md).
- [ ] **UNIX2 — FUSE write operations.** Prerequisite: UNIX-D1.
- [ ] **UNIX3 — Real file attributes.** `getattr` reports `mtime`, `ctime` and size from the object record and mode, uid and gid from the `unix-*` values (UNIX-DESIGN "Selected design"), with the defaults UNIX-D2 selects. Prerequisites: UNIX-D2, [METADATA7](metadata-implementation-plan.md).
- [ ] **UNIX4 — Symlinks under `/paths/`.** Model `ImportKind::Symlink` in `VfsEntryKind`. Prerequisites: UNIX-D1, UNIX-D3.
- [ ] **UNIX5 — FUSE mount integration tests.** A test target that mounts, lists and reads through FUSE where the host allows unprivileged mounts (`user_allow_other`), skipped with a reported reason elsewhere.
- [ ] **UNIX11 — Remove path contexts and export.** `unix-path-context`, scoped values (`Value::Scoped`, the dictionary `context` field), scope validation, `mimir project create-context | list-contexts | export`, `Exporter` and `ExportAction` go from `crates/types`, `crates/index`, `crates/unix`, `bin/mimir` and the demo ontology (UNIX-DESIGN "Rejected alternatives"). Acceptance: no `Scoped` or `unix-path-context` remains in `crates/`, `bin/` or `demo-data/`; import and `/paths/` work without them.
- [ ] **UNIX10 — Content import.** `mimir project import` reads file contents into blobs, reuses an existing object when the BLAKE3 content hash matches (as METADATA-D6 selects), sets `unix-path`, mode, uid and gid, and reports created and deduplicated counts; `--auto-tag` asserts the unix-interop module's path-convention categories (`lang`, `type`). Prerequisites: [BLOB1](blob-implementation-plan.md), UNIX-D4, [METADATA-D6](metadata-decisions.md). Acceptance: importing a tree containing two identical files creates one object with two paths.
