# Encryption — implementation plan

Design: [encryption-design.md](encryption-design.md) · Decisions: [encryption-decisions.md](encryption-decisions.md) · Order: [operations-plan.md](operations-plan.md)

- [ ] **ENCRYPTION1 — Cipher modes in the transform.** `Encryptor` implements the SPECIFICATION-DESIGN§9.3 modes instead of returning `TransformError::EncryptionDisabled`. Prerequisite: ENCRYPTION-D1.
- [ ] **ENCRYPTION2 — Key hierarchy.** `MasterKEK → DiskKey`, real `TransformKey` material, `encryption_keyid` in the superblock. Prerequisites: ENCRYPTION-D3, ENCRYPTION-D4.
- [ ] **ENCRYPTION3 — Encrypted journal sets.** `JSET_FLAG_ENCRYPTED` on write and replay, one AES-256-GCM unit per jset under the pool's journal key — derived with the pool's `fs_uuid` — with the nonce and AAD of ENCRYPTION-DESIGN§1 and JOURNAL-DESIGN§1.2. Prerequisites: ENCRYPTION1, ENCRYPTION2, [JOURNAL9](journal-implementation-plan.md). Acceptance: two pools created under the same passphrase have different journal keys.
- [ ] **ENCRYPTION4 — Encrypted node blocks.** XTS on node-bucket blocks with the `(disk_id, bucket_no, generation, sector)` tweak, at the granularity ENCRYPTION-D6 selects; moving a node re-encrypts it. Prerequisites: ENCRYPTION1, ENCRYPTION2, ENCRYPTION-D6. Acceptance: the same node content written to a bucket before and after a generation bump produces different ciphertext.
- [ ] **ENCRYPTION5 — Encrypted data extents.** HCTR2 on private pieces, shared pieces and packed blocks with the owner-derived tweaks of ENCRYPTION-DESIGN§1, per object as ENCRYPTION-D6 selects. Prerequisites: ENCRYPTION1, ENCRYPTION-D6, [BLOB1](blob-implementation-plan.md). Acceptance: two objects sharing a piece read it back from one stored copy; a piece moved by copy GC decrypts without re-encryption; identical content in two objects with private pieces produces different ciphertext.
