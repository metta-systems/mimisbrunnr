# B+ tree regions — completed

- Packed-key codec persists elided value-prefix bytes inline in `SortedRunKeyFormat` — replaced by BTREE9's fixed-width key format.
- Packed-key codec supports `FIXED` and `VARINT` value sizes with auto-selection and a force-`VARINT` hint — replaced by BTREE9's fixed and variable value kinds.
- `JournalPin` covers a node's pending journal entries — `crates/storage/src/journal_pin.rs`, test `pin_covers_every_recorded_lsn_until_cleared`.
- BTREE1: packed-codec region API used by the chunk, forward and tag indices — replaced by BTREE9's `Region`.
- BTREE2: region reads reject a `BtreeKind` mismatch and drop a torn run — carried into BTREE9's `Region::open`.
- BTREE9: write-once regions — `BtreeNodeHeader` (`BREG`) written once in block 0, runs of an index block (`RunHeader`, `KeyFormat`, `RunBlockEntry`s, fence keys) and self-contained data blocks with fixed-width frame-of-reference keys, 8-aligned values, value blocks for large values and whiteouts; `Region::{create, create_in_place, open, append_run, append_entries, lookup, entries}`, a lookup reading one data block per run, load stopping at the first invalid run and dropping a torn newest run, encrypted runs refused; every keyed tree (bucket alloc, freespace, backpointers, object and location tables, chunk, forward, tag and range indices, ontology, subscriptions, placement rules, disk overflow) persists through it, CBOR trees as opaque values; the old `LoadedNode` / `SortedRun` / `BtreeRegion` layer, the bit-packed codec and the `FormatPromote` op gone — `crates/storage/src/region.rs` (tests in `region/tests.rs`: `header_block_fixed_bytes`, `index_and_data_block_fixed_bytes`, `lookup_reads_at_most_one_data_block_per_run`, `an_8_kib_value_is_read_8_byte_aligned`, `a_run_torn_in_its_last_data_block_is_dropped`, `an_encrypted_run_fails_to_load`, `rewriting_in_place_never_reads_the_previous_runs`, and others), `crates/storage/src/journal_pin.rs`, each consumer's region round-trip tests, `crates/engine/tests/integration.rs` (`object_table_on_disk_is_a_region_of_records`).
- BTREE12: `validation/` derives region capacity from the write-once structs — entries per entry block, blocks per index block, entries per one-run leaf, radix leaf and inner slots — and pins every figure the documents quote: 1 536 records and 12 288 / R slots per radix node, 6 511 object-table leaves, ~43 content-map entries per block, ~6 800 backpointers and ~23 000 buckets per leaf (and the ALLOCATION-DESIGN§1.1 table), ~2 800 forward leaves, ~4 000 tag terms per dictionary leaf; legacy per-run pins that no document quoted and the `SortedRunHeader` / bit-width `FieldFormat` mirrors gone; the figures corrected in BTREE-DESIGN§1.5, INDEX-DESIGN§4.3, METADATA-DESIGN§2.2, ALLOCATION-DESIGN§1.1 and FORMAT-DESIGN§16 — `validation/src/lib.rs`.
- BTREE10: positional page regions — `PageRegion::{create, open, read_page, write_pages, compact_into}` over `logical_pages` pages (48 in 256 KiB) written in page runs (`PageRunHeader` with region tag, `PageRunEntry`s), the newest copy winning, unwritten pages reading as zeros, a torn newest run dropped, backward chains through the owner's kind header and `BTREE_NODE_FLAG_HEAD_OF_CHAIN`; the unused `object_leaf.rs` and `location_leaf.rs` removed — `crates/storage/src/page_region.rs` (tests `changing_one_record_of_a_full_leaf_writes_8_kib`, `a_never_written_page_reads_as_zeros`, `a_chain_of_three_regions_appends_without_rewriting_the_first_two`, `a_torn_page_run_is_dropped_and_its_pages_read_their_previous_copy`, `a_page_run_left_by_an_earlier_region_is_not_read`, `a_full_region_compacts_into_a_fresh_one_with_the_newest_pages`, `page_run_header_fixed_bytes`). The forward-overflow chain moves onto them in INDEX14, the object table's radix in METADATA1.
- Region tag: every run header carries the low 32 bits of block 0's checksum and loading stops at a run with another tag, so a run left in reused space by an earlier region is never read — `crates/storage/src/region.rs` (`a_run_left_by_an_earlier_region_is_not_read_as_this_regions`, `index_and_data_block_fixed_bytes`).
- BTREE11: `Preamble { magic, version, kind }` and `Preamble::identify`, naming the superblock, region (with its `BtreeKind`), run index, page-run index and journal set from the first 8 bytes and rejecting any unknown `(magic, version, kind)` with `StorageError::UnknownStructure`; `BtreeKind` takes FORMAT-DESIGN§1.3's contiguous 0–26, the four kinds still in use outside the format at `0x8000`–`0x8003`, six unused ones gone — `crates/storage/src/preamble.rs` (tests `preamble_fixed_bytes`, `identify_names_each_structure`, `identify_rejects_what_it_does_not_know`), `crates/storage/src/block.rs` (`btree_kind_spec_discriminants_pinned`), `validation/src/lib.rs`.
- BTREE3: workspace builds; `cargo test --workspace`, `cargo clippy --workspace` and `cargo clippy --workspace --all-targets` are clean.
